# 🎯 IMIGRA.AI - MODELO DE NEGÓCIO REAL (RESUMIDO)

## ❌ PROBLEMA COM O PRIMEIRO MODELO

```
Ideia inicial:
"Vou cobrar R$ 19,90/mês dos imigrantes por um app"

Realidade:
- 67,4% dos imigrantes estão DESEMPREGADOS
- Quem está empregado ganha MENOS que brasileiro
- Não têm dinheiro para pagar R$ 19,90/mês
- É IMORAL cobrar de quem está em vulnerabilidade social
- App fica vazío = negócio fracassa
```

```

Matching inteligente com IA
Comunidade de suporte
Chat com orientações
```

```

   "Quero colocar meus imigrantes em melhores empregos"
   → Pagam comissão

4. CURSOS (3% da receita)
   "Quero certificado de português técnico"
   → R$ 49-199/curso

5. DADOS (2% da receita)
   "Quero entender o mercado de imigrantes"
   → Relatórios e insights
```

## 🌍 COMO CHEGA NAS PESSOAS? (Distribuição)

**Não usa publicidade cara (Google, Facebook, Instagram)**

Usa PARCERIAS (alcance organizado):

### 1️⃣ **ONGs** (13.000 usuários/mês)
```
ONG de apoio ao migrante:
- CAMI, Casa do Migrante, etc
- IMIGRA.AI oferece: app grátis + tablet + treinamento
- IMIGRA.AI paga: R$ 50/usuário ativo
- Resultado: 13k usuários/mês com custo baixo
```

### 2️⃣ **Igrejas** (4.000 usuários/mês)
```
Igrejas têm comunidades imigrantes fortes:
- Assembleia de Deus, mesquitas, templos, etc
- IMIGRA.AI oferece: smartphone + cartazes + apresentação
- IMIGRA.AI paga: R$ 30/usuário
- Resultado: 4k usuários/mês
```

### 3️⃣ **Cursos de Português** (1.700 usuários/mês)
```
Prefeituras oferem cursos de português para imigrantes:
- ~80 centros em São Paulo
- IMIGRA.AI integra no currículo
- Professor: "Use o app para buscar emprego"
- Resultado: 1.7k usuários/mês
```

### 4️⃣ **Consulados** (900 usuários/mês)
```
Novos imigrantes chegam → vão ao consulado:
- Consulado aponta para IMIGRA.AI
- Link na página, cartazes, email de boas-vindas
- Resultado: 900 usuários/mês
```

### 5️⃣ **Telecom (Claro, Vivo, Oi)** (9.500 usuários/mês)
```
Operadoras de celular:
- IMIGRA.AI pré-instalado no telefone
- 1M celulares vendidos/mês × 5% = 50k instalações
- 20% ativo = 10k usuários/mês
- Resultado: 9.5k usuários/mês (MAIOR canal)
```

### 6️⃣ **SINE** (1.750 usuários/mês)
```
Agência estatal de emprego (Ministério do Trabalho):
- ~1.000 unidades SINE no Brasil
- App integrado no site + computadores nas unidades
- Atendentes recomendam
- Resultado: 1.75k usuários/mês
```

### 7️⃣ **Delivery Apps (IFood, Uber Eats)** (700 usuários/mês)
```
Entregadores querem evoluir de carreira:
- IFood tem 200k entregadores, 10% imigrantes
- Aba no app: "Quer mudar de carreira?"
- Link para IMIGRA.AI
- Resultado: 700 usuários/mês
```

### Plus Viral (3.000 usuários/mês)
```
Usuário conta para amigo → cresce naturalmente
```
