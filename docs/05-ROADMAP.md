# 📅 ROADMAP — IMIGRA.AI

## 🎯 Visão Geral das Fases (6 Meses)

Este roadmap é **realista para um time de 4 pessoas** num contexto acadêmico (20h/semana).

---

## 🟡 FASE 1: DESCOBERTA E PLANEJAMENTO
### ⏱️ Semanas 1-4 (1 mês)

**Status:** ✅ EM ANDAMENTO

**O que faremos:** Definir exatamente o que será construído, para quem, e como.

### 📋 Tarefas:

| Tarefa | Responsável | Duração | Status |
|---|---|---|---|
| Validar personas com usuários reais | PM | 1 semana | ✅ FEITO |
| Definir user stories (casos de uso) | PM + Backend | 1 semana | ✅ FEITO |
| Criar protótipos de telas (wireframes) | Designer | 1 semana | ⏳ PRÓXIMO |
| Definir arquitetura técnica | Backend + Frontend | 1 semana | ✅ FEITO |
| Documentar requisitos funcionais | PM | 1 semana | ✅ FEITO |

### 🎯 Entregáveis:
- ✅ Documento de Personas - 4 personas bem definidas
- ✅ User Stories - Histórias de uso completas
- ✅ Wireframes - Esboços das telas principais
- ✅ Documento de Arquitetura - Sistema completo
- ✅ Especificação de Requisitos - Tudo documentado

---

### 📋 Tarefas:

|---|---|---|---|

### 🎯 Entregáveis:
- ✅ Design System Completo - Cores, tipografia, componentes

- ✅ API Documentation - Endpoints documentados
- ✅ Banco de Dados Schema - Estrutura SQL pronta
- ✅ Repositório de Código - Estrutura pronta

### ✅ Critério de Sucesso:
- ✓ Design aprovado e documentado
- ✓ Backend preparado e testado
- ✓ Frontend compila sem erros
- ✓ APIs documentadas

## 🎯 DEFINIÇÕES DE PRONTO ("DONE")

Um task é considerado **DONE** quando:
- ✓ Código escrito e testado
- ✓ Code review aprovado
- ✓ Documentação atualizada

- ✓ Testado em device real
