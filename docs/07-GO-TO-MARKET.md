# 🚀 GO-TO-MARKET (GTM) — Como Chegar nas Pessoas

## 🎯 Visão Geral

Este documento explica **como o IMIGRA.AI vai chegar nas pessoas** de forma real, prática e escalável.

---

## 📍 SITUAÇÃO ATUAL

### O Problema:

```
"Tenho um app incrível que resolve problema dos imigrantes.
Mas como que 108.000 imigrantes vão instalar?

Problema:
❌ Não têm dinheiro para publicidade
❌ Não fazem busca no Google por "app emprego imigrante"
❌ Não veem anúncios no Instagram
❌ Muitos não conhecem tecnologia avançada
❌ Falam espanhol, creole, árabe, não português
"
```

### A Solução:

```
✅ Distribuição via parceiros (ONGs, igrejas, SINE, telecom)
✅ Marketing B2B (convencer empresas, governo)
✅ Product-led growth (o app fala por si)
✅ Network effect (imigrante convida amigo)
✅ Organização/comunidade (alcance grassroots)
```

### 3️⃣ **Cursos de Português + Integração**

#### Quem oferece:

```
Prefeituras (secretarias de educação) oferecem:
- Cursos de português para imigrantes
- Aulas de integração/cultura
- Orientação profissional

Exemplo São Paulo:
- ~50 Centros de Formação de Educação do Bairro (CEB)
- ~30 unidades CEU (Centro de Educação Unificado)
- Total: 80 locais

Cada um tem:
- 40-60 alunos
- 3 turmas/ano
- Duração: 3 meses
```

#### Como funciona:

```
1. IMIGRA.AI propõe ao professor:
   "Vamos integrar IMIGRA.AI no currículo"

2. Professor usa em aula:
   ✅ Atividade: "Abra o app e preencha seu perfil"
   ✅ Exercício: "Escreva em português sua experiência profissional"
   ✅ Lição de vida: "Busque 3 vagas compatíveis no app"
   ✅ Tarefa: "Qual é seu score no matching?"

3. IMIGRA.AI oferece:
   ✅ Material didático (cartilha do professor)
   ✅ Plano de aula com atividades
   ✅ Suporte técnico na primeira aula
   ✅ Acesso para professor acompanhar progresso

4. Resultado:
   ✅ Alunos aprendem português E TAMBÉM buscam emprego
   ✅ Professores veem resultado (impacto social)
   ✅ Prefeitura divulga sucesso
```

## 🎯 ESTRATÉGIA POR FASE

### Fase 1: MVP + Pilot (Semanas 1-4)

```
Objetivo: Validar com 1 ONG

Ação:
1. Contato com CAMI (ONG bem conhecida)
2. Proposta: "App gratuito para seus usuários"
3. Deploy simples (MVP com 3 vagas fake)
4. 20 usuários testam
5. Coleta feedback
6. Iterate
```

### Fase 2: Primeiro Contrato (Semanas 5-8)

```
Objetivo: Primeiro contrato de receita

Ação:
1. Pitch para empresa tech (Nubank, Spotify)
   "Queremos contratar imigrantes qualificados"
2. Proposta: "Recrutamento premium: R$ 3.000/contratação"
3. Demo com 5 imigrantes (Python devs)
4. Contrato assinado
5. Primeira receita = prova de conceito
```

### Fase 3: Scale (Semanas 9-12)

```
Objetivo: 10 ONGs + 5 empresas

Ação:
1. Expandir para 10 ONGs (R$ 250k/mês)
2. Assinar 5 empresas (R$ 50k/mês = R$ 250k/mês)
3. Proposta SINE ao Ministério
4. Contato com 50 igrejas
5. Resultado: R$ 500k/mês
```

### Fase 4: Growth (Semanas 13-26)

```
Objetivo: 108k usuários, R$ 428k/mês receita

Ação:
1. Contrato SINE (R$ 200k/mês)
2. Contrato Telecom (R$ 170k/mês)
3. 30 ONGs ativas
4. 100 igrejas
5. 40 cursos de português
6. Resultado: R$ 428k/mês
```

## 💡 KEY SUCCESS FACTORS

### 1. **Parcerias são tudo**
```
Não é marketing, é partnership
Não é publicidade, é recomendação
```

### 2. **Começar pequeno**
```
1 ONG → 10 → 100
1 empresa → 5 → 50
```

### 3. **Impacto social é o melhor marketing**
```
ONG vê resultado → recomenda para amigos
Empresa vê imigrante bom → recomenda para concorrente
Padre vê comunidade feliz → divulga na missa
```

### 4. **Fazer trabalhar de graça primeiro**
```
Oferecer: Suporte, Materiais, Treinamento
Não cobrar: Primeiro mês
Resultado: Parceiro vira evangélico
```

### 5. **Dados mostram impacto**
```
"50 imigrantes contratados"
"Economia: R$ 500k em recrutamento"
"Desemprego reduzido em 5%"
→ Governo quer contratar
```
